# Biological Scoring Methodology

Cats are obligate carnivores with specific nutritional requirements: high animal protein, moderate fat, low carbohydrates (<10-15% DMB), and strict micronutrient balances (taurine, calcium:phosphorus).

---

## 1. Wet Food Scoring Criteria (0 - 100 Base)

| Factor | Condition | Impact |
| :--- | :--- | :--- |
| **Named Meat Content** | ≥ 50% named meat (frango, peru, etc.) | **+25 pts** |
| | ≥ 30% named meat | **+15 pts** |
| **Brand Baseline Prior** | Ultra-premium (Lily's Kitchen, Natural Greatness) | **+25 pts** |
| | Good Quality (Smaak, Gourmet Nature) | **+15 pts** |
| | Discount Basic (Continente Basic, Brekkies) | **-15 pts** |
| **Added Sugars** | Açúcar, xarope, caramelo | **-25 pts** (Severe penalty) |
| **Cereals / Grains** | Cereais, trigo, milho, arroz | **-15 pts** |
| **Vegetable Proteins** | Subprodutos vegetais, extratos de proteína vegetal | **-15 pts** |
| **Vague Byproducts** | Carnes e subprodutos animais (sem % de carne nobre) | **-15 pts** |
| **Protein DMB** | ≥ 55% Dry Matter Basis | **+15 pts** |
| | < 35% Dry Matter Basis | **-15 pts** |
| **Carbohydrates DMB** | ≤ 10% Dry Matter Basis | **+10 pts** |
| | > 25% Dry Matter Basis | **-15 pts** |

### Complete vs. Complementary
- **Alimento Completo**: Meets all FEDIAF dietary needs (vitamins, minerals, taurine).
- **Alimento Complementar**: Fillets/shreds in broth (e.g. standard Schesir, Applaws). Suitable only as a topper or treat, not an exclusive diet.

## 2. Dry Food Scoring Criteria (0 - 100 Base)

| Factor | Condition | Impact |
| :--- | :--- | :--- |
| **1st Ingredient** | High-quality animal protein first | **+15 pts** |
| | Grain / corn / vegetable protein first | **-20 pts** |
| **Grain-Free** | Formulated without cereals | **+15 pts** |
| **Corn Gluten** | Glúten de milho / proteína de milho | **-10 pts** |
| **Artificial Colorants** | Corantes (óxido de ferro, etc.) | **-15 pts** |
| **Protein %** | ≥ 40% Crude Protein | **+15 pts** |
| | ≥ 35% Crude Protein | **+10 pts** |
| | < 30% Crude Protein | **-15 pts** |
| **Fat % (Kittens)** | ≥ 18% Crude Fat (needed for growth) | **+10 pts** |
| | < 14% Crude Fat | **-10 pts** |
| **Carbohydrates % (NFE)** | ≤ 25% Carbs | **+15 pts** |
| | > 42% Carbs | **-15 pts** |

---

## 3. Tier Classification

- **Tier S (Ultra-Premium)**: Score 80-95 (Wet) / 85-95 (Dry)
- **Tier A (Excelente / Alto Teor Carne)**: Score 65-79 (Wet) / 70-84 (Dry)
- **Tier B (Médio-Alto / Boa Relação)**: Score 50-64 (Wet) / 55-69 (Dry)
- **Tier C (Básico / Ingredientes Genéricos)**: Score 35-49 (Wet) / 40-54 (Dry)
- **Tier D (Evitar / Açúcares e Glúten)**: Score < 35 (Wet) / < 40 (Dry)
